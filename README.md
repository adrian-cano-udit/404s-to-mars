# 404s-to-mars

See this web -> https://adrian-cano-udit.github.io/404s-to-mars

## Mission Objective:

Design and develop a 404 error page with a space theme: the planet Mars has vanished from the solar system. Your mission is to visually represent this cosmic event through design and effects.

## Approved Technologies:

-   HTML5, CSS3, and JavaScript (external libraries are allowed).

-   Creative use of animations and visual effects will be especially valued.

## Operational Requirements:

-   The project must be developed in teams of at least 5 crew members.

-   The source code must:

-   -   Be uploaded to a public GitHub repository.

-   -   Also be submitted on the UDIT Virtual Campus.
